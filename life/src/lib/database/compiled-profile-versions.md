# Compiled profile format versions

`COMPILED_PROFILE_VERSION` in `compiled-profile.ts` is bumped on every breaking change to the `.ahlifepro` shape.

- 1→2: added the cross-family `summary` block + precomputed headline aggregates on the `tsk`/`eoe` blobs and coverage entries.
- 2→3: added TSK epilogue-tally (`foundationTrustTally`/`cellDeceptionTally`) + exhaustive chaos-bag act counts (`bagActCounts`) on the `tsk` blob.
- 3→4: added `eligibilityInsights` — precomputed "eligible but unused" tallies per card (Vicious Blow & Deduction), the denominator spanning every deck.
- 4→5: added `totalDecks` — the all-decks count used as the "% of decks" denominator for the Charisma & Relic Hunter / Core Neutral insight percentages.
- 5→6: `eligibilityInsights` entries now carry used / removed-not-upgraded counts (+ their investigators) instead of the single not-used count.
- 6→7: `eligibilityInsights` entries also carry the not-used count + investigators alongside used / removed.
- 7→8: `eligibilityInsights` entries also carry the never-removed investigators (complement of removed among the used decks).
- 8→9: each `insightDecks` entry carries `cantripMax` (per-version distinct-cantrip max) for the corrected cantrip-diversity rows.
- 9→10: added the `dwl` blob — The Dunwich Legacy bespoke per-scenario tallies.
- 10→11: added the `ptc` blob — The Path to Carcosa bespoke per-scenario tallies.
- 11→12: added the `tfa` blob — The Forgotten Age bespoke per-scenario tallies.
- 12→13: added the `tcu` blob — The Circle Undone bespoke per-scenario tallies.
- 13→14: added the `tdea` + `tdeb` blobs — The Dream-Eaters bespoke per-scenario tallies + the shared interconnected view (Black Cat, Silver Key, Randolph, epilogue matrix).
- 14→15: added `soloClearGrid` + `trueSoloClearGrid` — the 1-player-filtered clear grids (previously dropped, so a loaded/compiled-profile viewer couldn't render the Solo / True Solo Campaign Clears widgets). Each row's `name` is still re-derivable → dropped.
- 15→16: added the `tic` blob — The Innsmouth Conspiracy bespoke per-scenario tallies.
- 16→17: added the `fhv` blob — The Feast of Hemlock Vale bespoke per-scenario tallies.
- 17→18: added the `tdc` blob — The Drowned City bespoke per-scenario tallies.
- 18→19: Return-to campaigns are now first-class families (own code, not folded into the base) — the artifact's `family` keys change for rt* plays.
- 19→20: added the `notz` blob — The Night of the Zealot bespoke per-scenario tallies.
- 20→21: PtC blob extended — Unspeakable Oath insane-investigators (subject-scoped), Echoes per-player-count resolution table, Last King slain-at-the-party VIPs; and Dim Carcosa `possessed` dropped as a win ending (epilogue trigger, not a win).
- 21→22: resolutionCoverage scenarios gained per-scenario `succeed`/`failed` tallies, derived generically from campaign-data `scenarioMeta.resolutionOutcomes` (the shared per-scenario Succeed/Failed source the scenario passport reads).
- 22→23: added the unified `scenarios` structure — one per-scenario record per campaign (plays / Succeed / Failed / resolutions reached + verdicts / VP highscore / choices), the single per-scenario source that supersedes `scenarioXp` + `resolutionCoverage`.
- 23→24: removed the now-redundant `scenarioXp` + `resolutionCoverage` structures — `scenarios` is the sole per-scenario source in the contract.
- 24→25: PtC `doubtConvictionRuns` gained per-play `tokenRoute` (chaos-token mix per scenario), `outcome` (win/loss/abandoned) + `difficulty`; plus new `dcSources` (per-change Conviction/ Doubt/Neutral by difficulty) and `tokenScenarioMixes` (per-scenario token coverage).
- 25→26: PtC runs gained `outcomeKey` (the finale ending log key → shared outcome-face text) and `dcSources` rows gained `canNeutral` (sources that never go neutral show a dash).
- 27→28: PtC runs gained `phantomVersion` / `oathVersion` (serialized Act-version per play); the Phantom + Unspeakable Oath blobs gained per-version `versions` tallies; `vipSlainHome` replaced by richer `vipHelp` (per home scenario: VIP card pair + interview-bonus + slain-here counts).
- 28→29: `ScenarioStat` gained the unified `versions` per-version breakdown (plays / Succeed / Failed / resolutions / XP per version), the single source for the shared version table.
- 29→30: removed the now-redundant bespoke per-version blobs — the EotE `eoeCity` matrix, PtC `phantom`/`unspeakableOath` `versions`, and DWL `ascendingHill` — all superseded by `ScenarioStat.versions` (every versioned scenario reads the one structure).
- 30→31: PtC `vipHelp` bonus / slainHere widened from a plain count to `{ total, byTier }` so the VIP header's two numbers hover to a per-difficulty breakdown like every other count.
- 31→32: retired TSK's bespoke per-variant blobs (`scenarioVariant{Tallies,Plays,Outcomes}`) — its version + tier rows now live in `ScenarioStat.versions` via a MULTI-AXIS registry entry, so the whole per-version model is unified (every versioned scenario, TSK included, reads one structure).
- 32→33: PtC `pallidMask`/`blackStarsRise` `randomizedWeaknesses` changed from a `code→count` map to a `{ weakness, bearer, count }[]` grouped by (weakness, drawing investigator) — the new `randomized_weakness_investigator` Extra picker attributes each random weakness to its bearer.
- 33→34: PtC chaos-token route/coverage corrected — the route ends at the TERMINAL scenario (Carcosa merged ⇒ Black Stars Rise, not Dim Carcosa); only completed (win/loss) runs count; and the receiver "base" mix is dropped (a receiver always gets a mix; an empty one is unknown data).
- 34→35: PtC random-weakness draws (Pallid Mask / Black Stars Rise) are scoped to the viewed subject's investigators — a weakness attributed to a teammate's investigator no longer shows on a single-player profile (a play group still merges every member's).
- 35→36: PtC Echoes `byPlayerCount` entries hold resolution-derived `{ succeed, failed, tallies }` (per-player-count Succeed / Failed via the shared version breakdown) instead of `{ plays, resolutions }`; no_resolution counts as a Failed rather than vanishing into the play total.
- 36→37: PtC Doubt/Conviction runs dropped `consistent` / `recordedConviction` / `recordedDoubt` — the chain-vs-recorded-meter mismatch check is no longer surfaced in the profile UI.
- 37→38: added `standalones` — the first-class Standalone Archive aggregates (per scenario: plays / win-loss / resolution coverage / best score / deck XP-range tier distribution). Only each scenario's `name` is stripped (re-derived from its catalogue); everything else is the contract.
- 38→39: PtC Curtain Call's Stranger-defeat count is derived from the warn-police resolution (2 if you went to the police either way, else 1) instead of a manual Extra counter, which is no longer asked.
- 39→40: PtC investigator codes (insane / possessed / random-weakness bearer) are canonicalized to their base printing, so a parallel / promo investigator matches the roster + groups as one.
- 40→41: PtC chaos-token route carries the bag forward — a scenario whose transition adds no special tokens keeps the previous mix (the persisted bag) instead of an empty step, in the chain + coverage.
- 41→42: PtC Dim Carcosa blob gained `strangerArrivalDoom` — plays per agenda-1a doom tier set by the Chasing-the-Stranger tally at arrival (final tally minus the marks earned within Dim Carcosa).
- 42→43: PtC widget-table batch — Curtain Call's `strangerOnToYou` became `didntReachAct2b` (plays that ended Curtain Call before the theater turned); `strangerByScenario` now lists EVERY Stranger scenario (0-defeat ones included, shown as a dash); and Pallid Mask / Black Stars Rise `randomizedWeaknesses` are per-draw `{ weakness, bearer, finishDate }` (newest first, cap 7) instead of (weakness, bearer)- grouped counts — the lists are now a dated chronological log.
- 43→44: PtC Dim Carcosa `strangerArrivalDoom` is now per-doom-tier `{ succeed, failed, tallies }` (the shared per-version breakdown, doom tier as the axis — Succeed / Failed / Resolutions, no Plays) instead of a plain doom → play count; only plays that recorded a Dim Carcosa resolution.
- 44→45: PtC Dim Carcosa `possessedInvestigators` is now LOG-derived — read from the repeatable `possessed` campaign-note `#name#` picks (a new `possessedInvestigators` record field) instead of the dropped Extra picker — and reshaped to a subject-scoped, newest-first `{ code, finishDate }[]` list.
- 45→46: PtC VIP tallies (`vipsInterviewed`, `vipsSlain`, `lastKing.slainVips`) widened from plain counts to `TierCount` (per-difficulty split for the portrait hovers), and `lastKing` gained `mostSlainInRun` (the highest single-run party-slain count + the most-recent such run's guests).
- 46→47: PtC trimmed + corrected — dropped Curtain Call `didntReachAct2b` and Pallid Mask `knowSiteOfGate` (always-true / unreliable); Oath `insaneInvestigators` reshaped to dated `{ code, finishDate }[]` (newest first); Black Stars Rise `carcosaMerged` is discriminated from Dim Carcosa's R4 by explicit resolution (naive note → BSR); Dim Carcosa gained `carcosaMerged` (R4).
- 47→48: TCU blob rebuilt to PtC parity — the Lodge-vs-Coven allegiance spine (`allegianceRuns` per-play lean chains + `allegianceSources` per-decision Lodge/Coven/neutral by difficulty + `allegiance` lean summary/Josef), missing-persons Union survival, mementos coverage, Wages-of-Sin heretics distribution, the Inner Circle + Union faction states, the four-ending finale, and the Twist-of-Fate `pathWinds` → finale table; Union and Disillusion gained a derived Cosmos version axis in `ScenarioStat.versions`. Removed the phantom `covenVictory` (a non-existent log id).
- 48→49: The Dream-Eaters — precomputed `evidenceOfKadath.avg` (tdea) and `stepsOfTheBridge.avg` (tdeb) so the widgets read a serialized mean instead of computing it hot. Render-only otherwise.
- 49→50: The Forgotten Age `tfa` blob rebuilt to PtC parity — per-play `runs`, the Poisoned/Venom aggregate, the Harbinger per-appearance trajectory + `neverDamaged`, `suppliesEmptyRuns`, the Yithian aftermath, and re-sourced hidden-log facts (Ichtaca conversation, HotE consult, final depth) + fixed composite-keyed counts (harbinger_alive, paths_known) — so the blob recomputes.
- 50→51: The Innsmouth Conspiracy `tic` blob widened from flat counts to per-difficulty `Tally` on every field (memories/keys/equipment/harper + all per-scenario branches), powering the shared difficulty hovers; suspect/hideout/equipment gained card codes — recompute.
- 51→52: NotZ blob rebuilt to full parity — every count widened to a per-difficulty `Tally`; The Gathering gained `litaRecruited` + Ghoul Priest `slain` (crossed-off) vs `survived`; The Midnight Masks gained per-cultist caught/escaped tallies, `playsWithEscapes`, and a best-single-play `bestHaul` highscore; the finale endings are tallies; and a new `purist` blob counts Core-Set-only clears (deck-derived via `CampaignRecord.coreOnly`) + the investigators who achieved them — so it recomputes.
- 52→53: The Drowned City `tdc` blob rebuilt for per-scenario passports — the flat fork objects give way to a `scenarios` note-tally map; artifacts gained `kept` (carried into the finale), tasks gained `picked`/`obligations` + the per-investigator `assignments` (Extra one_last_job.task_assignment), and the doom gained `flooded` neighborhoods — so the blob recomputes.
- 53→54: The Feast of Hemlock Vale `fhv` blob rebuilt for the full widget suite — villager tallies gained the danced/stood/sacrificed arc; new `dance`, `hemlockHouse` (Argument + Little Sylvie), `longestNight` (captives + Rachel stance + captives-damage Extras), `finalEvening`, and `bertie` blobs; and `scenarios` re-keyed by full `section.id` — so the blob recomputes.
- 54→55: TCU Union and Disillusion — the missing-persons Union survival totals (alive/dead) are summed into a `union.survivors` field at precompute instead of hot in the widget — recompute.
- 56→57: Dunwich `dwl.broodCounts` re-keyed from `Record<number, number>` to a per-difficulty `Record<string, Tally>` so the Undimensioned and Unseen brood counts hover to a per-tier breakdown — so the blob recomputes.
- 57→58: Return-to merge — the new `mergeReturnToStats` setting (default ON) folds each Return-to campaign's plays into its BASE family too, across clears / win-loss / endings / scenarios / resolution coverage / trauma / standalone usage / collections / special interactions and the bespoke blobs, with Return-to scenarios kept as their own rows. `hideReturnToCampaigns` (default OFF) additionally drops the separate Return-to pages. The family keys + per-family tallies change (trauma events gained a `families` array), so the artifact recomputes.
- 58→59: the refactor release.
  - The twelve per-campaign arrays became one `bespoke` object keyed by family code (`profile.bespoke.tskc`, `profile.bespoke.eoe`, …), each blob an object instead of a one-element array.
  - `dwl`: `persons[].kidnapped` → `leftKidnapped`; `broodCounts`/`broodPlays` → the ascending `broods` list.
  - `eoe`: `mementosEarned`, `roster` and `fatalMiragePlays` removed; min/max pairs became `frost`, `shelter`, `banishedPerRun` extents; `miasma` and `iceAndDeath` grouped.
  - `notz`: `midnightMasks.bestHaul` → `{tier, caught}[]`; `purist.investigators` → `{code, clears}[]`; `playsWithEscapes` removed.
  - `tskc`: `routes`, `scenarioPlays`, `scenarioOutcomes`, `logCounts` and the trust/deception act counts removed; added `routeHighlights`, `variantRoutes`, `recentVersion`, `epilogue`, `dealings`, `onThinIce`; routes are `{steps, time, finishDate}`; `keys` is an ordered array; Dead Heat bests are sorted arrays.
  - `ptc`: `doubtConviction`, `strangerPlays`, `tokensProduced`, `echoes.byPlayerCount`, `dimCarcosa.strangerArrivalDoom` removed; `dcRuns`/`tokenRuns` hold the three signature runs; `dcSources` and `tcu.allegianceSources` share one side-keyed `SourceTally` shape; `tokenMixes`, `stranger`, `strangerHighscores`, `curtainCall.act2b` reshaped; `WeaknessDraw.weakness` → `code`.
  - `tcu`: `pathWinds` and `allegiance.lodgeLed/covenLed/balanced` removed; `missingPersons`, `mementos`, `wagesOfSin.hereticsReleased` are ordered arrays.
  - `tfa`: runs live in `vengeance.runs`; `depthsAgenda`, `poison.byInvestigator` sorted arrays; `harbinger` and `depthsOfYoth` are extents; `doomOfEztli.retriesMax`; `turnBackTime` tallies.
  - `tic`: `memories`, `keys`, `equipment` are `{each, all(, distinct)}`.
  - `tdea`/`tdeb`: `shared.family/plays` removed; Black Cat `trail`; Steps of the Bridge `bands`; `bestSigns` added.
  - `tdc`: `doom` folded into `scenarios.the_doom_of_arkham` + `flooded`; `glyphs.byScenario`, `sepulchre.innerSanctum` added.
  - `fhv`: counts became `Tally`s; `fate`, `rachelExtra`, `simeonExtra`, `hemlockHouse` folded into `villagers`, `finalEvening`, `argument` and `scenarios`; `valeSummary` added.
  - `scenarios[].versions` gained Echoes of the Past (player count), Dim Carcosa (arrival doom), Before the Black Throne (path winds) and Fate of the Vale.
