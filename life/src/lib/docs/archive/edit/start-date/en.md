Just the start or finish date alone can help identify what you played in what years.

It is ideal if both start and finish dates are provided. Searching your archive for a specific date will then hit any date between start and finish. It also helps a calendar-like visualization show how long it took to finish the campaign, accounting for all the off days in between.
