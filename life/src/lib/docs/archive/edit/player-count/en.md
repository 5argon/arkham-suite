How many players this campaign should be considered as, for your profile and the campaign widgets.

The players and decks you add **imply** a count, but don't fix it — so you control it here:

- **Auto** (default) — the number of players added to this campaign, capped at 4. Good for the common
  case.
- **1 / 2 / 3 / 4** — an explicit override. Use this when people dropped in and out, or you actually
  played at a lower (or different) count than the bodies present imply.
- **Unspecified** — deliberately record no player count.

"Auto" is resolved to a concrete number when your profile is compiled, so a later change to the
participants is reflected the next time it rebuilds.
