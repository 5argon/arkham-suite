This team is assembled from decks across multiple of [HungryColquhoun](/starter/hungry-colquhoun)'s starter deck series, where their overlaps are only a few of Core Set neutral skill cards and a reprinted Vicious Blow. Those overlaps were resolved for your convenience by arkham-starter.com's editor. Follow these links to read the play guide written for each deck.

- <span class="icon-guardian"></span> **Daniela Reyes** — [Hurting for Clues](/starter/hungry-colquhoun/ch2-starter-guide/hurting-for-clues) (SG)
- <span class="icon-seeker"></span> **Joe Diamond** — [The Drawlord](/starter/hungry-colquhoun/ch2-core-only/joe-diamond-the-drawlord) (CO)
- <span class="icon-survivor"></span> **Isabelle Barnes** — [Jenny's Retribution](/starter/hungry-colquhoun/ch2-starter-guide/jennys-retribution) (SG)
- <span class="icon-rogue"></span> **André Patel** — [Money Buys Happiness](/starter/hungry-colquhoun/ch2-starter-guide/money-buys-happiness) (SG)

In the team's name, **3C+1ID** means 3 Core Set investigators and 1 Investigator Deck investigator, and the letters after each name are the deck's series: **CO** is [Chapter 2 Core Only](/starter/hungry-colquhoun/ch2-core-only/) and **SG** is [Chapter 2 Starter Guide](/starter/hungry-colquhoun/ch2-starter-guide/).

### Class Access

In a 4 player team with 3 Core Set investigators, there are 2 possible outcomes :

- They span 4 classes, because they form a chain where each overlaps with the next in the class access. (Chain)
- They span all 5 classes, because only 2 of them overlap in the class access. (Not a chain)

In the first case, we would have 1 "vacant" class that can be conveniently filled with the corresponding Investigator Deck investigator, and so solved 4 players team composition easily.

In the 2nd case, no class is left vacant, so the Investigator Deck investigator will step on one of the classes of the 3 Core Set investigators. It is still possible to find a way out but harder.

In this team, Daniela, Joe and Isabelle form a **chain**, with Daniela next to Joe and Daniela next to Isabelle, and therefore cover 4 classes : Guardian, Survivor, Seeker, Mystic. André accordingly filled in the vacant class.

Daniela and Joe both run 2 copies of Vicious Blow. The Core Set has 2 and Tommy's Investigator Deck has another 2. This team already uses cards from Tommy's deck, so Daniela takes those copies.
