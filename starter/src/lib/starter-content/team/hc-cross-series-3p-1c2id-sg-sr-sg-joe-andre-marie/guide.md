This team is assembled from decks across multiple of [HungryColquhoun](/starter/hungry-colquhoun)'s starter deck series, where their cards do not overlap. Follow these links to read the play guide written for each deck.

- <span class="icon-seeker"></span> **Joe Diamond** — [Shoot First, Questions Later](/starter/hungry-colquhoun/ch2-starter-guide/shoot-first-questions-later) (SG)
- <span class="icon-rogue"></span> **André Patel** — [The Fatal Thespian](/starter/hungry-colquhoun/ch2-starters-revisited/the-fatal-thespian) (SR)
- <span class="icon-mystic"></span> **Marie Lambeau** — [Blood Money](/starter/hungry-colquhoun/ch2-starter-guide/blood-money) (SG)

In the team's name, **1C+2ID** means 1 Core Set investigator and 2 Investigator Deck investigators, and the letters after each name are the deck's series: **SG** is [Chapter 2 Starter Guide](/starter/hungry-colquhoun/ch2-starter-guide/) and **SR** is [Ch2 Starters Revisited](/starter/hungry-colquhoun/ch2-starters-revisited/).

### Class Access

In a 3 player team with 1 Core Set investigator, they span 2 classes. The 2 Investigator Deck investigators can fill 2 other classes and reach 4 classes in total. If one of them shares the Core Set investigator's second class instead, the team only reaches 3 classes.

In this team, Joe covers Seeker and Guardian. André and Marie accordingly filled in Rogue and Mystic, and nobody on this team can use Survivor.
