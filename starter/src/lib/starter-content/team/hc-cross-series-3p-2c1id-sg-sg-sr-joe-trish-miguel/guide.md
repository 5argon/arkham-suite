This team is assembled from decks across multiple of [HungryColquhoun](/starter/hungry-colquhoun)'s starter deck series, where their cards do not overlap apart from a reprinted Deduction. Follow these links to read the play guide written for each deck.

- <span class="icon-seeker"></span> **Joe Diamond** — [Shoot First, Questions Later](/starter/hungry-colquhoun/ch2-starter-guide/shoot-first-questions-later) (SG)
- <span class="icon-rogue"></span> **Trish Scarborough** — [Pocket Sand!](/starter/hungry-colquhoun/ch2-starter-guide/pocket-sand) (SG)
- <span class="icon-survivor"></span> **Miguel de la Cruz** — [Disaster Artist](/starter/hungry-colquhoun/ch2-starters-revisited/disaster-artist) (SR)

In the team's name, **2C+1ID** means 2 Core Set investigators and 1 Investigator Deck investigator, and the letters after each name are the deck's series: **SG** is [Chapter 2 Starter Guide](/starter/hungry-colquhoun/ch2-starter-guide/) and **SR** is [Ch2 Starters Revisited](/starter/hungry-colquhoun/ch2-starters-revisited/).

### Class Access

In a 3 player team with 2 Core Set investigators, there are 2 possible outcomes :

- They span 3 classes, because they overlap in the class access. (Adjacent)
- They span 4 classes, because they didn't overlap in the class access. (Not adjacent)

In the first case, we would have 2 "vacant" classes. The Investigator Deck investigator can fill only one of them, so one class stays out of reach for the whole team.

In the 2nd case, we would have only 1 vacant class. The Investigator Deck investigator can fill it and the team can reach all 5 classes.

In this team, Joe and Trish are **adjacent** and therefore cover 3 classes : Seeker, Guardian, Rogue. Miguel accordingly filled in one of the vacant classes, and nobody on this team can use Mystic.

Joe and Trish both run 2 copies of Deduction. The Core Set has 2 and Carolyn's Investigator Deck has another 2. This team already uses cards from Carolyn's deck, so Trish takes those copies.
