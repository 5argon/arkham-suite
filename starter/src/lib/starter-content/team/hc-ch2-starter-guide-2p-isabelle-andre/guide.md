### Class Access

In a 2 player team with 1 Core Set investigator, they span 2 classes. The Investigator Deck investigator can fill another class and reach 3 classes in total. If they share the Core Set investigator's second class instead, the team only reaches 2 classes.

In this team, Isabelle covers Survivor and Mystic. André accordingly filled in Rogue, and nobody on this team can use Guardian or Seeker.
