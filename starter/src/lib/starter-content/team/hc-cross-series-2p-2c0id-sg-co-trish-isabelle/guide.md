This team is assembled from decks across multiple of [HungryColquhoun](/starter/hungry-colquhoun)'s starter deck series, where their cards do not overlap. Follow these links to read the play guide written for each deck.

- <span class="icon-rogue"></span> **Trish Scarborough** — [Pocket Sand!](/starter/hungry-colquhoun/ch2-starter-guide/pocket-sand) (SG)
- <span class="icon-survivor"></span> **Isabelle Barnes** — [Mad Skillz](/starter/hungry-colquhoun/ch2-core-only/izzie-barnes-mad-skillz) (CO)

In the team's name, **2C+0ID** means 2 Core Set investigators and 0 Investigator Deck investigators, and the letters after each name are the deck's series: **CO** is [Chapter 2 Core Only](/starter/hungry-colquhoun/ch2-core-only/) and **SG** is [Chapter 2 Starter Guide](/starter/hungry-colquhoun/ch2-starter-guide/).

### Class Access

In a 2 player team with 2 Core Set investigators, there are 2 possible outcomes :

- They span 3 classes, because they overlap in the class access. (Adjacent)
- They span 4 classes, because they didn't overlap in the class access. (Not adjacent)

With only 2 players, some classes always stay out of reach : 2 classes in the first case, and 1 class in the 2nd case.

In this team, Trish and Isabelle are **not adjacent** and therefore cover 4 classes : Rogue, Seeker, Survivor, Mystic, and nobody on this team can use Guardian.
