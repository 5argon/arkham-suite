This team is assembled from decks across multiple of [HungryColquhoun](/starter/hungry-colquhoun)'s starter deck series, where their overlaps are only a few of Core Set neutral skill cards and a reprinted Deduction. Those overlaps were resolved for your convenience by arkham-starter.com's editor. Follow these links to read the play guide written for each deck.

- <span class="icon-seeker"></span> **Joe Diamond** — [Shoot First, Questions Later](/starter/hungry-colquhoun/ch2-starter-guide/shoot-first-questions-later) (SG)
- <span class="icon-rogue"></span> **Trish Scarborough** — [Pocket Sand!](/starter/hungry-colquhoun/ch2-starter-guide/pocket-sand) (SG)
- <span class="icon-mystic"></span> **Dexter Drake** — [The Prestige](/starter/hungry-colquhoun/ch2-core-only/dexter-drake-the-prestige) (CO)
- <span class="icon-survivor"></span> **Miguel de la Cruz** — [Rancher Rambo](/starter/hungry-colquhoun/ch2-starter-guide/rancher-rambo) (SG)

In the team's name, **3C+1ID** means 3 Core Set investigators and 1 Investigator Deck investigator, and the letters after each name are the deck's series: **CO** is [Chapter 2 Core Only](/starter/hungry-colquhoun/ch2-core-only/) and **SG** is [Chapter 2 Starter Guide](/starter/hungry-colquhoun/ch2-starter-guide/).

### Class Access

In a 4 player team with 3 Core Set investigators, there are 2 possible outcomes :

- They span 4 classes, because they form a chain where each overlaps with the next in the class access. (Chain)
- They span all 5 classes, because only 2 of them overlap in the class access. (Not a chain)

In the first case, we would have 1 "vacant" class that can be conveniently filled with the corresponding Investigator Deck investigator, and so solved 4 players team composition easily.

In the 2nd case, no class is left vacant, so the Investigator Deck investigator will step on one of the classes of the 3 Core Set investigators. It is still possible to find a way out but harder.

In this team, Joe, Trish and Dexter form a **chain**, with Joe next to Trish and Trish next to Dexter, and therefore cover 4 classes : Seeker, Guardian, Rogue, Mystic. Miguel accordingly filled in the vacant class.

Joe and Trish both run 2 copies of Deduction. The Core Set has 2 and Carolyn's Investigator Deck has another 2. This team already uses cards from Carolyn's deck, so Trish takes those copies.
