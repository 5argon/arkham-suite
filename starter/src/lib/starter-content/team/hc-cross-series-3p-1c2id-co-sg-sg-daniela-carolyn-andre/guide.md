This team is assembled from decks across multiple of [HungryColquhoun](/starter/hungry-colquhoun)'s starter deck series, where their cards do not overlap. Follow these links to read the play guide written for each deck.

- <span class="icon-guardian"></span> **Daniela Reyes** — [Arkham Linebacker](/starter/hungry-colquhoun/ch2-core-only/daniela-reyes-arkham-linebacker) (CO)
- <span class="icon-seeker"></span> **Carolyn Fern** — [Who Looks Inside, Awakes](/starter/hungry-colquhoun/ch2-starter-guide/who-looks-inside-awakes) (SG)
- <span class="icon-rogue"></span> **André Patel** — [Money Buys Happiness](/starter/hungry-colquhoun/ch2-starter-guide/money-buys-happiness) (SG)

In the team's name, **1C+2ID** means 1 Core Set investigator and 2 Investigator Deck investigators, and the letters after each name are the deck's series: **CO** is [Chapter 2 Core Only](/starter/hungry-colquhoun/ch2-core-only/) and **SG** is [Chapter 2 Starter Guide](/starter/hungry-colquhoun/ch2-starter-guide/).

### Class Access

In a 3 player team with 1 Core Set investigator, they span 2 classes. The 2 Investigator Deck investigators can fill 2 other classes and reach 4 classes in total. If one of them shares the Core Set investigator's second class instead, the team only reaches 3 classes.

In this team, Daniela covers Guardian and Survivor. Carolyn and André accordingly filled in Seeker and Rogue, and nobody on this team can use Mystic.
