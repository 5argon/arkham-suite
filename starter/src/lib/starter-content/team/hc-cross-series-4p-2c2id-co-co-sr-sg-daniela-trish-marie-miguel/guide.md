This team is assembled from decks across multiple of [HungryColquhoun](/starter/hungry-colquhoun)'s starter deck series, where their overlaps are only a few of Core Set neutral skill cards. Those overlaps were resolved for your convenience by arkham-starter.com's editor. Follow these links to read the play guide written for each deck.

- <span class="icon-guardian"></span> **Daniela Reyes** — [Arkham Linebacker](/starter/hungry-colquhoun/ch2-core-only/daniela-reyes-arkham-linebacker) (CO)
- <span class="icon-rogue"></span> **Trish Scarborough** — [I Spy a Seeker](/starter/hungry-colquhoun/ch2-core-only/trish-scarborough-i-spy-a-seeker) (CO)
- <span class="icon-mystic"></span> **Marie Lambeau** — [Marie Poppin' Cultists](/starter/hungry-colquhoun/ch2-starters-revisited/marie-poppin-cultists) (SR)
- <span class="icon-survivor"></span> **Miguel de la Cruz** — [Rancher Rambo](/starter/hungry-colquhoun/ch2-starter-guide/rancher-rambo) (SG)

In the team's name, **2C+2ID** means 2 Core Set investigators and 2 Investigator Deck investigators, and the letters after each name are the deck's series: **CO** is [Chapter 2 Core Only](/starter/hungry-colquhoun/ch2-core-only/), **SG** is [Chapter 2 Starter Guide](/starter/hungry-colquhoun/ch2-starter-guide/) and **SR** is [Ch2 Starters Revisited](/starter/hungry-colquhoun/ch2-starters-revisited/).

### Class Access

In a 4 player team with 2 Core Set investigators, there are 2 possible outcomes :

- They span 3 classes, because they overlap in the class access. (Adjacent)
- They span 4 classes, because they didn't overlap in the class access. (Not adjacent)

In the first case, we would have 2 "vacant" classes that can be conveniently filled with corresponding Investigator Deck investigators, and so solved 4 players team composition easily. Or you can still intentionally choose one that does overlap with the 2 Core Set investigators if there are underutilized cards left.

In the 2nd case, one of the Investigator Deck investigators will step on one of the classes of the 2 Core Set investigators. It is still possible to find a way out but harder.

In this team, Daniela and Trish are **not adjacent** and therefore cover 4 classes : Guardian, Survivor, Rogue, Seeker. Marie accordingly filled in the vacant class. Miguel is the one who needs to clash with Daniela.
