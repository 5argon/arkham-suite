### Class Access

In a 3 player team with 2 Core Set investigators, there are 2 possible outcomes :

- They span 3 classes, because they overlap in the class access. (Adjacent)
- They span 4 classes, because they didn't overlap in the class access. (Not adjacent)

In the first case, we would have 2 "vacant" classes. The Investigator Deck investigator can fill only one of them, so one class stays out of reach for the whole team.

In the 2nd case, we would have only 1 vacant class. The Investigator Deck investigator can fill it and the team can reach all 5 classes.

In this team, Daniela and Dexter are **not adjacent** and therefore cover 4 classes : Guardian, Survivor, Mystic, Rogue. Carolyn accordingly filled in the vacant class.
