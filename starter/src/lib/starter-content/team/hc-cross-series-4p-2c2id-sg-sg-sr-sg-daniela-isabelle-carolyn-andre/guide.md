### Class Access

In a 4 player team with 2 Core Set investigators, there are 2 possible outcomes :

- They span 3 classes, because they overlap in the class access. (Adjacent)
- They span 4 classes, because they didn't overlap in the class access. (Not adjacent)

In the first case, we would have 2 "vacant" classes that can be conveniently filled with corresponding Investigator Deck investigators, and so solved 4 players team composition easily. Or you can still intentionally choose one that does overlap with the 2 Core Set investigators if there are underutilized cards left.

In the 2nd case, one of the Investigator Deck investigators will step on one of the classes of the 2 Core Set investigators. It is still possible to find a way out but harder.

In this team, Daniela and Isabelle are **adjacent** and therefore cover 3 classes : Guardian, Survivor, Mystic. Carolyn and André accordingly filled in the 2 vacant classes.
