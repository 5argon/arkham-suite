This team is assembled from decks across multiple of [HungryColquhoun](/starter/hungry-colquhoun)'s starter deck series, where their cards do not overlap. Follow these links to read the play guide written for each deck.

- <span class="icon-guardian"></span> **Tommy Muldoon** — [Tommy²](/starter/hungry-colquhoun/ch2-starters-revisited/tommy-squared) (SR)
- <span class="icon-seeker"></span> **Carolyn Fern** — [Who Looks Inside, Awakes](/starter/hungry-colquhoun/ch2-starter-guide/who-looks-inside-awakes) (SG)

In the team's name, **0C+2ID** means 0 Core Set investigators and 2 Investigator Deck investigators, and the letters after each name are the deck's series: **SG** is [Chapter 2 Starter Guide](/starter/hungry-colquhoun/ch2-starter-guide/) and **SR** is [Ch2 Starters Revisited](/starter/hungry-colquhoun/ch2-starters-revisited/).

### Class Access

In a 2 player team with only Investigator Deck investigators, each one uses their own class only, so the team reaches exactly 2 classes.

In this team, Tommy and Carolyn cover Guardian and Seeker, and nobody on this team can use Rogue, Mystic or Survivor.
