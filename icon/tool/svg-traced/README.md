# Icons traced by hand

Stand-ins for icons no icon project has yet, traced by hand from whatever FFG has shown. `../generate.ts`
turns every SVG in this folder into a component, like the ones in `../svg-arkham-build/`. Delete a file
once the real icon is in the ArkhamCards IcoMoon export or arkham.build, and point `ProductIcon` at that
instead.

Each is centred in a square viewBox so it lines up with the other product icons, and has no fill of its
own so it takes the text colour.

| File | Component | Traced from |
| --- | --- | --- |
| `power_of_the_dreamlands.svg` | `PowerOfTheDreamlands` | The upright cat in the medallion in FFG's Power of the Dreamlands promotional video. |
